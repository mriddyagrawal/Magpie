Step 1: PARSER (parser.py)
  Test Summaries/*.md  →  ParsedSummary objects
  (just text extraction, no AI involved)
        ↓
Step 2: EMBEDDING (embeddings.py)
  ParsedSummary.title + summary + keywords
        ↓
  all-MiniLM-L6-v2 turns that text into a 384-dim dense vector
        ↓
Step 3: SPARSE ENCODING (also in embeddings.py)
  ParsedSummary.keywords + key_entities
        ↓
  BM25 tokenizer turns those into sparse vector (term → weight pairs)
        ↓
Step 4: STORE IN QDRANT (db.py)
  For each document, Qdrant stores:
  ┌─────────────────────────────────────────┐
  │  dense_vector:  [0.23, -0.11, ...]      │  ← from MiniLM
  │  sparse_vector: {"flight": 1.2, ...}    │  ← from BM25
  │  payload: {source_path, title, ...}     │  ← raw fields
  └─────────────────────────────────────────┘
        ↓
Step 5: SEARCH (search.py)
  User query → embed with MiniLM + BM25 tokenize
             → Qdrant finds best matches using BOTH vectors
             → returns ranked results
