# MTH-245 Handout 2: Nonparametric Inference for Population Medians

This statistics handout introduces the binomial distribution as foundational knowledge for conducting nonparametric inference on population medians. It presents the five-step Sign Test procedure for hypothesis testing, including test statistic calculation using the binomial distribution, p-value determination, and Cohen's h effect size interpretation. The document applies these methods to an R-based case study analyzing MFAP4 biomarker levels in 542 liver fibrosis patients, comparing values against healthy controls. Additional sections cover nonparametric confidence intervals using both exact binomial methods and percentile bootstrap resampling, with complete R code implementations using the BSDA and tidyverse packages.
