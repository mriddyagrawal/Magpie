# CSC-223 Assignment 4: Abstract Syntax Tree and Builder Pattern Implementation

This document outlines a programming assignment requiring students to implement an Abstract Syntax Tree (AST) class hierarchy for the DEC programming language, including expression nodes (VariableNode, LiteralNode, BinaryOperator subclasses) and statement nodes (BlockStmt, AssignmentStmt, ReturnStmt). Students must implement recursive Unparse methods to convert ASTs back to source code with proper indentation for debugging and pretty-printing. The assignment also requires implementing the Builder pattern through DefaultBuilder and DebugBuilder classes to separate AST construction from structural analysis, enabling different construction strategies without changing client interfaces. Deliverables include xUnit tests, proper documentation, and in-person demonstration of the implementation to the instructor.
