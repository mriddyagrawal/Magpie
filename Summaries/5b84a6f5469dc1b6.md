# MTH-245 Handout 11: Multiple Comparisons Corrections for Mood's Median Test Follow-ups

This educational handout explains follow-up procedures to Mood's median test for identifying which specific population medians differ while controlling the family-wise error rate. It details the Bonferroni and Benjamini-Hochberg (BH) corrections for multiple pairwise hypothesis tests and simultaneous confidence intervals, including mathematical definitions and R implementations using the `rcompanion` and `pairwiseCI` packages. The document demonstrates practical applications with percentile bootstrap confidence intervals and a case study analyzing hippocampal volume differences among football players with and without concussion histories.
