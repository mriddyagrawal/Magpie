# MTH 245 Handout 10: Mood's Median Test for Multiple Samples

This educational handout introduces Mood's Median Test as a nonparametric alternative to one-way ANOVA for comparing population medians across t groups when normality or equal variance assumptions are violated. The document presents a five-step hypothesis testing framework using a chi-squared test statistic calculated from observed and expected counts of observations falling above and below the grand median. It illustrates the procedure through a detailed case study analyzing hippocampal volumes in college football players with and without concussion histories versus healthy controls (Singh et al., 2014), complete with R code examples using the RVAideMemoire and effectsize packages to conduct the test and calculate effect sizes (Cramer's V).
