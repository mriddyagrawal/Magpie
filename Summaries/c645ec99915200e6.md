# MTH-245 Handout 13: ANOVA for Regression, Model Conditions, and Inference

This statistics handout presents ANOVA for regression by partitioning total variability (SST) into model (SSR) and residual (SSE) components to conduct overall F-tests for model significance. It establishes six conditions for regression use, including checks for residual normality, constant variance, and multicollinearity assessment via Variance Inflation Factors (VIF) and generalized VIF (GVIF) for categorical predictors. The document details statistical inference procedures for individual regression parameters using t-tests and confidence intervals, illustrated with R code analyzing the Palmer Penguins dataset to predict body mass from bill dimensions, sex, and species.
