# CSC-223 Lab 2: Hierarchical Symbol Table Implementation

This programming assignment requires students to implement a generic `SymbolTable<TKey, TValue>` class using two parallel doubly-linked lists to support nested scoping and variable shadowing for the DEC declarative language. The implementation must satisfy the C# `IDictionary<TKey, TValue>` interface while maintaining parent-child hierarchical relationships between symbol tables to enable scope chain lookups, and provide local-only query methods (`ContainsKeyLocal`, `TryGetValueLocal`) that do not traverse parent scopes. Special handling is required for shadowing semantics where an inner scope variable can reference its outer scope value during initialization before being assigned its own value. Students must create comprehensive xUnit tests (with LLM assistance permitted), document their code properly, and demonstrate successful test execution to the instructor in person.
