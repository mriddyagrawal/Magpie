# CSC-223 Assignment 5: DEC Language Parser Implementation

This computer science assignment requires implementing a recursive descent parser for the DEC (declarative) programming language as the third component in a compiler development series, connecting previous tokenizer and AST implementations. Students must implement static methods in a Parser class to transform token sequences into hierarchical AST representations according to formal BNF grammar rules supporting variable assignments, return statements, nested blocks, and binary expressions. The implementation strategy follows a bottom-up approach utilizing recursion for nested structures, SymbolTable for variable scoping, and ParseException for syntax error handling, with all functionality validated against provided unit tests.
