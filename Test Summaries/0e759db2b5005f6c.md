# CSC-223 Lab 5: DEC Parser Implementation Assignment

This CSC-223 assignment requires students to implement a recursive descent parser for the DEC (Declarative Educational Computer) language, integrating previous tokenizer and AST components into a compiler front-end. Students must create a static Parser class that transforms token sequences into an Abstract Syntax Tree according to formal BNF grammar rules supporting block statements, assignments, return statements, and parenthesized binary expressions with operators (+, -, *, /, //, %, **). The implementation requires specific methods—including ParseExpression, ParseAssignmentStmt, ParseBlockStmt, and ParseStmtList—using recursion to handle nested blocks and expressions while maintaining variable scoping via a SymbolTable. The parser must validate that programs start with '{' and end with '}', throw ParseException errors for invalid syntax, and pass provided unit tests demonstrating correct AST generation for valid DEC source code.
