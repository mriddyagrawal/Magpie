# MTH-245 Handout 2: Sign Test and Nonparametric Inference for a Population Median

This statistics course handout introduces nonparametric methods for inference on a population median M. It begins with the binomial distribution, illustrating probability calculations and R functions (choose, dbinom, pbinom) using a Pittsburgh Pirates baseball example. The document details the five-step Sign Test for hypothesis testing about a median, including conditions for use, test statistic calculation (S ~ binomial), and Cohen's h effect size. A worked example analyzes MFAP4 biomarker data (n=542) from liver fibrosis patients to test whether median levels exceed 7.9 U/mL. The handout concludes with two methods for constructing confidence intervals for the median: exact intervals based on the binomial distribution (using the BSDA package) and percentile bootstrap intervals (R=5000 resamples).
