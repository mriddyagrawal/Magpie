# CSC-223 Lab 3: DEC Tokenizer Implementation Assignment

This document outlines Assignment 3 for CSC-223, requiring students working in pairs to implement a lexical analyzer (tokenizer) for the DEC programming language using C#. The assignment involves creating a Tokenizer namespace containing a TokenType enumeration, a static TokenConstants class, and a Token class to encapsulate token values and types, alongside a TokenizerImpl class that implements a character-by-character scanning algorithm to convert source code into a List<Token>. Students must handle token categories including variables (lowercase alphabetic), the return keyword, numeric literals (integers and floats), operators (arithmetic and assignment :=), and structural delimiters (parentheses and curly braces), while utilizing Char struct methods and raising ArgumentException for invalid characters. Deliverables include comprehensive xUnit tests with [Fact] and [Theory] attributes, proper code documentation, and an in-person demonstration of the implementation to the instructor.
