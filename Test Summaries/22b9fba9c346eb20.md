# CSC-223 Assignment 3: DEC Language Tokenizer

This programming assignment instructs student pairs to implement a lexical analyzer (tokenizer) for the DEC language in C# as the initial phase of a compiler construction project. Students must develop a `Tokenizer` namespace containing a `Token` class (with `TokenType` enumeration and `TokenConstants` static class) and a `TokenizerImpl` class that implements a character-by-character `Tokenize` method to generate tokens for variables, keywords (e.g., `return`), literals, operators (e.g., `:=`), and grouping symbols. The assignment requires handling specific DEC syntax rules, utilizing `System.Char` methods, creating comprehensive xUnit tests, adhering to documentation standards, and collaborating via Git/GitHub.

**Content type:** code

**Keywords:** tokenizer, lexical analysis, DEC language, compiler construction, C#, xUnit testing, TokenType enumeration, symbol table, parsing, Git collaboration
