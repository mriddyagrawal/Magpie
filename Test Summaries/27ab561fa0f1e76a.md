# MTH 245 Handout 3: Statistical Inference for a Population Proportion

This educational handout covers statistical inference methods for a single population proportion, detailing both exact and approximate approaches. It presents the Pearson-Clopper hypothesis test and confidence interval, which rely on the binomial distribution and require no sample size conditions, alongside large-sample methods based on the Central Limit Theorem, including the z-test and Wald/Wilson confidence intervals. The document explains the use of Cohen’s h for measuring effect size and describes the construction of percentile bootstrap confidence intervals. R code examples are provided throughout, illustrated with two case studies: a thermal neuromodulation device for chronic low back pain (n=32) and a two-drug HIV treatment regimen (n=152).
