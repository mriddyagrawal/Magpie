# MTH-245 Handout 3: Statistical Inference for Population Proportions

This educational handout presents statistical inference methods for a population proportion $p$, covering both exact and approximate approaches. It details the Pearson-Clopper hypothesis test and confidence interval, which utilize the exact binomial distribution and are appropriate for small samples without requiring the Central Limit Theorem. For large samples, the document explains the Z-test for proportions (including continuity correction), Wald confidence intervals, and Wilson confidence intervals, along with the underlying chi-squared distribution theory. Additionally, it covers percentile bootstrap confidence intervals and effect size calculation using Cohen's h. The handout includes practical R code examples applying these methods to medical research studies, such as evaluating pain relief device efficacy and HIV treatment success rates.
