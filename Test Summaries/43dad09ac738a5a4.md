# MTH-245 Handout 14: Variable Transformations and Standardization in Linear Regression

This statistics handout details techniques for remedying violations of linear regression assumptions, specifically non-normality and non-constant variance of residuals, through variable transformation. It provides R code examples demonstrating log transformations of response variables and polynomial (square) transformations of quantitative predictors to improve model fit, as measured by R-squared and adjusted R-squared statistics. The document also explains centering and scaling (standardization) of predictors using z-scores to facilitate coefficient interpretation and comparison, illustrating both pre-fitting data transformation and in-formula standardization methods using the scale() function.
