# CSC-223 Lab 4: AST and Builder Pattern Implementation Assignment

This assignment directs student pairs to implement an Abstract Syntax Tree (AST) class hierarchy for the DEC language, including expression nodes (LiteralNode, VariableNode, and BinaryOperator subclasses like PlusNode and TimesNode) and statement nodes (BlockStmt, AssignmentStmt, ReturnStmt) with recursive Unparse methods for source code regeneration and indentation-aware pretty-printing. Students must also implement DefaultBuilder and DebugBuilder classes using the Builder pattern to decouple AST construction from structural analysis, allowing different construction strategies alongside a provided NullBuilder. Requirements include comprehensive xUnit testing with [Fact] and [Theory] attributes, adherence to commenting standards, Git-based collaboration, and in-person demonstration of functioning code.
