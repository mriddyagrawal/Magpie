# MTH-245 Handout 5: The Chi-Squared Test for Association

This educational handout introduces the chi-squared (χ²) test for association as a nonparametric method to determine relationships between two categorical variables. It presents a five-step hypothesis testing framework including hypotheses formulation, conditions checking (representative sample, independence, and expected counts ≥5), calculation of the test statistic Q = Σ((O-E)²/E) with degrees of freedom (r-1)(c-1), p-value determination, and decision-making with effect size calculation using bias-corrected Cramer's v. The document explains the intuition behind comparing observed and expected counts in contingency tables and provides a detailed worked example examining the association between caffeine treatment and necrotizing enterocolitis (NEC) in premature infants using R statistical software. Additionally, it discusses Yates' continuity correction for approximating discrete distributions with the continuous chi-squared distribution.
