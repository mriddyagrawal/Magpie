# MTH-245 Handout 5: The Chi-Squared Test for Association

This educational handout introduces the chi-squared ($\chi^2$) test for association, a nonparametric hypothesis test used to determine if two categorical variables are related. It presents a five-step testing procedure covering hypotheses formulation, conditions for use (including expected counts ≥5), calculation of the test statistic $Q = \sum\sum \frac{(O_{rc}-E_{rc})^2}{E_{rc}}$ with degrees of freedom $\nu=(r-1)(c-1)$, and effect size measurement using bias-corrected Cramer's $v$. The document includes a detailed case study analyzing the association between caffeine treatment and necrotizing enterocolitis (NEC) in premature infants using a 2×2 contingency table, accompanied by R code demonstrating both manual calculations and the `chisq.test()` function. It concludes with an explanation of Yates' continuity correction for 2×2 tables when approximating discrete distributions with the continuous $\chi^2$ distribution.
