# MTH-245 Handout 9: Tukey HSD and the Multiple Comparisons Problem

This statistics handout explains the multiple comparisons problem that arises when conducting pairwise hypothesis tests following a significant one-way ANOVA, demonstrating how family-wise confidence levels decrease with multiple tests. It introduces Tukey's Honest Significant Difference (HSD) as a post-hoc procedure to maintain the overall confidence level when comparing multiple group means. The document provides a detailed R code example analyzing MFAP4 biomarker data from 542 hepatitis C patients across five fibrosis stages (Stage 0-4), showing how to calculate and interpret Tukey-adjusted confidence intervals and p-values to identify specific group differences while controlling for error inflation.
