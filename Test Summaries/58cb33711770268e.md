# MTH-245 Handout 9: Multiple Comparisons and Tukey HSD Post-Hoc Analysis

This statistics handout addresses the multiple comparisons problem that arises when conducting pairwise hypothesis tests following a significant one-way ANOVA, demonstrating how family-wise confidence levels decrease as the number of comparisons increases. It presents Tukey's Honest Significant Difference (HSD) as the standard post-hoc procedure to maintain the desired family-wise confidence level when comparing multiple group means, providing the mathematical formulas for Tukey intervals and test statistics. The document applies these methods to a biomedical case study evaluating MFAP4 as a serum biomarker for differentiating hepatitis C fibrosis severity across five Desmet-Scheuer stages (Bracht et al., 2016), including complete R code using TukeyHSD(), interpretation of adjusted p-values and confidence intervals for all ten pairwise comparisons, and ggplot2 visualization. The handout concludes with a caution regarding violated statistical assumptions (normality and constant variance) and their impact on result validity.
