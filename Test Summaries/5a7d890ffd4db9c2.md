# CSC-223 Lab 0: Utilities & Xunit Tests Assignment Specification

This document outlines Assignment 0 for CSC-223, directing student pairs to implement ten reusable utility methods in C# within a Utilities/Utilities.Tests project structure and accompany them with comprehensive xUnit test suites. The required methods in GeneralUtils.cs include generic array operations (Contains<T>, Duplicates, GetUniqueItems), string processing (ToCamelCase, IsPasswordStrong, IsValidVariable), and mathematical functions (CalculateAverage), with strict requirements for exception handling, input validation, and single-responsibility design. Students must adhere to rigorous documentation standards including XML comments, standardized header blocks, inline comments for code blocks, and region directives, while utilizing xUnit's [Fact] and [Theory] attributes for testing; the guidelines explicitly permit LLM-assisted test generation but mandate thorough review for correctness. Submission requires an in-person demonstration of successful test execution to the instructor, emphasizing clean code principles, proper parameter validation, and foundational software engineering practices.
