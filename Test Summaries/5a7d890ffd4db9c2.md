# CSC-223 Lab 0: Utility Functions and xUnit Testing Assignment

This document outlines Assignment 0 for CSC-223, requiring students to work in pairs to implement ten reusable utility methods in C# within a structured project containing separate Utilities and Utilities.Tests folders. Students must implement specific methods in GeneralUtils.cs—including Contains, ToCamelCase, IsPasswordStrong, CalculateAverage, and Duplicates—emphasizing single-responsibility principles, proper parameter validation, and exception handling. The assignment requires comprehensive xUnit testing using [Fact] and [Theory] attributes, detailed XML documentation comments for all methods, and adherence to specific commenting standards including mandatory header templates and region directives. Submission involves in-person demonstration of successful unit test execution to the instructor, with guidance provided on using LLMs for generating test cases while emphasizing the need for careful review.
