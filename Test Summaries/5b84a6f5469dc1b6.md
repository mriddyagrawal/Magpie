# MTH-245 Handout 11: Post-Hoc Procedures and Multiple Comparisons Corrections for Mood's Median Test

This educational handout provides follow-up procedures to Mood's median test for identifying which specific population medians differ across multiple groups while controlling the family-wise error rate. It details two correction methods—the conservative Bonferroni adjustment (which multiplies p-values by the number of comparisons m) and the less strict Benjamini-Hochberg procedure (which controls the false discovery rate)—for both simultaneous hypothesis testing and confidence interval construction. The document includes R code examples utilizing the `rcompanion` and `pairwiseCI` packages to perform pairwise median tests and calculate percentile bootstrap intervals, demonstrated through an analysis of hippocampal volumes in college football players with and without concussion histories compared to healthy controls.
