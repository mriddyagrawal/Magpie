# CSC-223 Lab 1: Doubly-Linked List Implementation in C#

This document outlines a paired programming assignment requiring students to implement a generic doubly-linked list (DLL<T>) in C# using head and tail sentinel nodes. Students must create a DNode class and DLL class implementing IEnumerable<T> and IList<T> interfaces, with methods for insertion, deletion, indexing (PushFront, PopBack, Remove, etc.), and proper exception handling. The assignment emphasizes Git/GitHub collaboration workflows including feature branching, pull requests, and code reviews. Implementation requires using EqualityComparer<T>.Default.Equals for comparisons, StringBuilder for ToString methods, and comprehensive xUnit unit testing within a specified project structure (src/Utilities/Containers).
