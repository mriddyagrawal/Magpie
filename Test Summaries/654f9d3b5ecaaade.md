# CSC-223 Doubly-Linked List Implementation Assignment

This document outlines a programming assignment requiring pairs of students to implement a generic doubly-linked list (DLL<T>) in C# using head and tail sentinel nodes. The implementation must support the IEnumerable<T> and IList<T> interfaces to enable foreach iteration and indexer access, while providing core methods such as PushFront, PushBack, PopFront, PopBack, and Insert. Students must collaborate via GitHub using feature branches, pull requests, and code reviews, organizing code in src/Utilities/Containers and corresponding xUnit test directories. The assignment requires thorough xUnit testing, proper use of EqualityComparer<T> for element comparisons, and StringBuilder for efficient ToString implementations.
