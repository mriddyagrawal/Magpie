# MTH-245 Handout 12: Introduction to Linear Regression Analysis with R

This educational handout introduces general linear regression models for fitting, interpreting, and assessing relationships between continuous response variables and mixed predictor types. Using Spotify track data (energy, loudness, acousticness, speechiness, mode, and artist), it demonstrates exploratory data analysis via scatter plots, correlation coefficients, and correlograms with the GGally package. The document explains least squares estimation for obtaining fitted models in R using the `lm()` function, progressing from simple to multiple regression. Detailed coverage is given to incorporating categorical predictors through indicator (dummy) variables and reference group coding, illustrating how categorical variables shift model intercepts while maintaining common slopes across groups.
