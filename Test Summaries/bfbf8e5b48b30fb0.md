# MTH-245 Handout 12: Linear Regression Models with Categorical Predictors

This educational handout introduces general linear regression models for fitting, interpreting, and assessing relationships between continuous response variables and both quantitative and categorical predictors. Using Spotify track data (energy, loudness, speechiness, acousticness, mode, artist), it demonstrates exploratory data analysis techniques including correlograms and correlation matrices in R, followed by the least squares method for estimating regression parameters. The document provides detailed R code examples for fitting simple and multiple linear regression models using the lm() function, and explains how to handle categorical predictors through indicator (dummy) variables, interpret reference groups (e.g., 'Major' mode, 'AGO' artist), and understand how these variables shift model intercepts while maintaining common slopes.

**Keywords:** linear regression, multiple regression, categorical predictors, indicator variables, dummy variables, least squares estimation, R programming, exploratory data analysis, correlation analysis, Spotify dataset, reference groups
