# MTH-245 Handout 13: ANOVA for Regression Analysis and Statistical Inference

This academic handout from an MTH-245 course explains Analysis of Variance (ANOVA) in the context of multiple linear regression, demonstrating how to partition total variability into model and residual components to conduct overall F-tests for predictor significance. It establishes six essential regression conditions for use, including residual normality, constant variance, and multicollinearity assessment using Variance Inflation Factors (VIF). The document provides a complete practical example using the Palmer Penguins dataset to illustrate hypothesis testing and confidence interval construction for individual regression parameters, with accompanying R code utilizing the `rms`, `car`, and `palmerpenguins` packages.
