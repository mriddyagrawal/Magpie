# MTH-245 Handout 4: Inference for Difference in Two Population Means

This statistics handout provides comprehensive methods for statistical inference on the difference between two independent population means (μ1 − μ2). It establishes the Central Limit Theorem for sampling distributions of mean differences, presents parametric hypothesis testing procedures using Welch's two-sample t-test (assuming unequal variances), and covers effect size calculation via Hedge's g. The document mathematically derives confidence interval formulas and introduces percentile bootstrap methods as a nonparametric alternative. A detailed practical example analyzes Spotify track danceability data comparing The Front Bottoms (n=61) and Manchester Orchestra (n=77), demonstrating R code implementation, hypothesis test results (t≈0.349, p=0.364), and interval estimation techniques.
