# CSC-223 Lab 2: Hierarchical Symbol Table Implementation

This document outlines a programming assignment requiring students to implement a generic hierarchical symbol table (`SymbolTable<TKey, TValue>`) using parallel doubly-linked lists to support nested scoping and variable shadowing for the DEC declarative language. The implementation must satisfy the C# `IDictionary<TKey, TValue>` interface while providing additional methods for local scope-only operations (`ContainsKeyLocal`, `TryGetValueLocal`) and parent-child relationships to manage scope hierarchies. Students work in pairs to build this core compiler data structure, which tracks variable definitions across nested blocks and handles shadowing scenarios where inner scope variables temporarily hide outer scope definitions.
