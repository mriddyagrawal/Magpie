# MTH-245 Handout 7: Nonparametric Inference for Comparing Population Medians

This educational handout presents nonparametric methods for comparing two population medians (M₁ − M₂), specifically Mood's Median Test and bootstrap confidence intervals. Mood's Median Test is described as a chi-squared test of association applied to a 2×2 contingency table classifying observations by group and their position relative to the grand median, with procedures for calculating test statistics, p-values (using Yates continuity correction via the RVAideMemoire package), and bias-corrected Cramer's v effect sizes. The document also details the construction of percentile bootstrap confidence intervals for median differences, including sampling conditions and R implementation. Both methods are illustrated using Spotify track popularity data comparing major and minor musical modes, with complete R code for hypothesis testing and bootstrap procedures.
