# MTH-245 Handout 7: Mood's Median Test and Bootstrap Confidence Intervals for Two Population Medians

This educational handout introduces nonparametric statistical inference for comparing two population medians (M₁ − M₂), specifically Mood's Median Test and the percentile bootstrap confidence interval method. Mood's Median Test is presented as a chi-squared test of association (χ² with ν=1) applied to a 2×2 contingency table of observations falling above or below the grand median, including a five-step hypothesis testing framework and effect size calculation using bias-corrected Cramer's v. The document provides a detailed R implementation using Spotify track popularity data (comparing major vs. minor musical modes), demonstrating both manual calculations and the RVAideMemoire package functionality while addressing the Yates continuity correction. Additionally, the handout covers the bootstrap procedure for constructing confidence intervals for median differences, illustrated with 5,000 resamples from the same dataset, ultimately finding no statistically significant difference between modes (95% CI: [-2, 9]).
