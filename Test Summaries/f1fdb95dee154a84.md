# CSC-223 Lab 7: Control Flow Graph Generation Assignment

This document details a pair-programming assignment requiring students to implement a Control Flow Graph (CFG) system for analyzing program execution paths in a DEC language compiler. Students must build upon previous Visitor pattern work by implementing a generic `DiGraph<T>` class using an adjacency list representation, a `CFG` class inheriting from `DiGraph<Statement>`, and a `ControlFlowGraphGeneratorVisitor` to construct CFGs from Abstract Syntax Trees (ASTs). The assignment explains CFG theory for compiler optimization (illustrated via constant propagation), specifies xUnit testing requirements with LLM-assisted test generation permitted, and requires in-person demonstration of functioning code.
