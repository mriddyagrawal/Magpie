# CSC-223 Lab 7: Control Flow Graph Generation Assignment

This programming assignment requires implementing a Control Flow Graph (CFG) generator to analyze program execution paths for compiler optimization. Students must build a generic DiGraph<T> class using adjacency list representation with a DLL, create a CFG class extending DiGraph<Statement> with a nullable Start property, and implement a ControlFlowGraphGeneratorVisitor to transform Abstract Syntax Trees (ASTs) into CFGs containing only AssignmentStmt and ReturnStmt nodes. The assignment emphasizes constant propagation optimization, requires comprehensive xUnit testing with [Fact] and [Theory] attributes, and builds upon previous Visitor pattern implementations using C# and Git collaboration.
