# MTH-245 Handout 1: Statistical Inference for a Population Mean

This statistics course handout provides a comprehensive guide to inferential methods for a single population mean (μ), covering both parametric and nonparametric approaches. It explains the Central Limit Theorem (CLT) and sampling distributions, details a five-step hypothesis testing procedure using the t-test (including effect size calculation via Hedge's g), and derives the formula for parametric confidence intervals. The document distinguishes parametric methods, which assume specific population distributions, from nonparametric alternatives such as bootstrap resampling, explaining how to construct percentile bootstrap confidence intervals. A detailed case study analyzing the pH levels of 53 Florida lakes demonstrates practical implementation using R code for hypothesis testing, confidence intervals, and bootstrap procedures.
