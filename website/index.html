Privacy by design

Your files never leave
your machine. Period.

Your files

Indexed where they already sit. Never uploaded, never copied into a second store. Delete a file and the next sync drops it from the index.

The index

Qdrant runs as a local binary on loopback. Point Magpie at a remote cluster and it hard-errors. That is enforced in code, not in a policy page.

The models

Embeddings, sparse retrieval, visual page understanding and reranking all run inside the app. None of the four ever call out.

The one honest boundary. Answers can be written locally or in the cloud. In Local mode nothing leaves the machine at all. In Cloud mode your question and the text of the files retrieved to answer it are sent to the LLM provider. Worth knowing before you point Magpie at anything sensitive.

How it works

Eight things your
search bar can't do

Answers, not hit lists

Every answer names the files it relied on, as clickable paths you can open or reveal in the file manager.

Reads what others skip

Scanned pages and photos go through a visual model that embeds the rendered page instead of giving up on it.

Two embeddings, not one

Dense vectors so "pay the landlord" finds "rent payment". Sparse BM25 so PHY-312 and $143.50 stay findable literally.

Tables stay row-addressable

A three-sentence summary indexes a receipt fine. A 1,724-row course catalog is indexed per row, so single courses stay findable.

Incremental by default

A manifest tracks every file. Add one file to a folder of thousands and exactly one file is re-processed.

The filesystem stays the truth

Nothing is duplicated into a parallel library. Your folders remain the only place your documents live.

Routed to the cheapest tier

Plain text embeds directly. Documents get extracted. Receipts get a structured summary. Huge files are registered and grepped on demand.

Out of your way

Global ⌥Space to summon, arrow keys through sources, ⏎ to open, esc to dismiss. Never a window you have to manage.

All release assets & checksums

macOS: the first launch is blocked

The beta is unsigned and un-notarized, so macOS quarantines it. This is expected. Run this once, or open System Settings → Privacy & Security and click Open Anyway.

xattr -dr com.apple.quarantine /Applications/Magpie.app

Windows: SmartScreen will warn you

Same reason, no code-signing certificate on the beta. Click More info, then Run anyway. The installer and its SHA-256 digest are both published on the release page if you'd like to verify them first.

Get-FileHash .\Magpie_0.1.0_x64-setup.exe

First question needs a connection. Magpie downloads ~90 MB of embedding models once, then works from cache.
Intel Macs aren't built (GitHub retired the runner). Linux isn't in this beta, but it builds from source.

FAQ

Questions, answered

Does Magpie upload my documents anywhere?
No. Your files are indexed in place and never copied or uploaded. In Local mode nothing leaves the machine at all. In Cloud mode two things do: your question, and the text of the specific files retrieved to answer it, sent to the LLM provider that writes the answer. That's the whole boundary, and it's the only one.
What does it actually run on my machine?
Four models: MiniLM for dense embeddings, BM25 for sparse retrieval, ColPali for visual pages, and a cross-encoder for reranking. Plus Qdrant as a local vector database bound to loopback. None of them make network calls.
How big does the index get?
Small next to the documents themselves, since it stores vectors and short summaries, not copies. The first run also pulls ~90 MB of embedding models, and a visual model (500 MB to 2 GB) the first time it meets a scanned PDF or an image.
Is the local, fully-offline model ready?
Not in this installer. Magpie fully supports on-device answering, but the ~2 GB llama-server runtime isn't bundled yet and there's no in-app downloader, so choosing Settings → Local will tell you so and point you back to Cloud. If you run from source, just install-llama-server gets you offline answering today.
How well does it actually retrieve?
On a hand-written 35-question set over our internal corpus, 34 of 35 answers cited every expected source with one distractor. Read that honestly: our questions, our corpus, a small N, and a different answer model than the beta ships with. Treat it as a regression test we haven't gamed, not a benchmark win. The harness is in tests/ if you want to run it on your own files.
Why is the app unsigned?
Code-signing certificates cost money and this is a beta from two people. macOS and Windows will both warn you; the workarounds are one command and one click, both above. Signing is on the list.
Is there a Linux build?
Not in this beta. See docs/DEVELOPMENT.md for why. The source builds on Linux, and the whole project is AGPL-3.0, so nothing stops you.
What does it cost?
Nothing. It's open source under AGPL-3.0. The beta ships with a shared, spend-capped key against a free-tier model so Cloud mode works out of the box. Assume that key is public, and bring your own for anything private.
